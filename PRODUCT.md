# Vault

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Jacob Springer and reviewers evaluating his Python application development goal. Visitors use a public demo account to explore generated financial data.

## Product Purpose

Demonstrate a complete Python application: database schema, authenticated FastAPI REST API, and a Streamlit dashboard consuming that API. The goal is a finished, credible demonstration for the November 2026 review.

## Capabilities and Constraints

- JWT login, income/spending monthly charts, category summaries, sign out.
- Generated sample data only. Never use real financial, personal, or Palmer Holland data.
- Preserve the working API and Streamlit stack. This work changes the presentation.
- Render hosts the API; Streamlit Community Cloud hosts the dashboard.
- Free API hosting can delay first requests after inactivity.

## Brand Commitments

Name: Vault. Jacob requests a white-background style and rejects the generic dark-card AI-dashboard aesthetic. A distinctive, coherent redesign is required, beyond changing the color palette.

## Evidence on Hand

Working application and public demo. Existing source in dashboard/app.py and dashboard/style.css. No commercial claims, testimonials, or real user financial records.

## Product Principles

- Make sample-data status clear before login.
- Present finances clearly with exact reporting context.
- Keep the application small and easy to demonstrate.
- Prefer useful data and typography over decorative dashboard chrome.
